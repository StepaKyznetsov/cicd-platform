### Цель проекта

Закрепление навыков фронтенд-разработки, включая создание семантической, валидной, полностью адаптивной и доступной вёрстки с использованием современного CSS-фреймворка, а также применение актуальных методов оптимизации и инструментов разработки.

### Установка

1. Клонируйте репозиторий

2. Выполните установку зависимостей

```bash
npm install
```

3. Запустите локальный сервер с авто-сборкой

```bash
npm run dev
```

4. Откройте браузер, перейдите по адресу `http://localhost:8080`
